释放回忆，而非个人数据。Simon-Galleria 是一款兼具强大功能与隐私保护的终极照片和视频应用。没有广告，没有不必要的权限——只有为您量身打造的流畅体验。

**🖼️ 触手可及的照片编辑：**  
用我们简单而强大的照片编辑器美化您的照片。裁剪、调整大小、旋转、翻转、绘制并应用惊艳的滤镜，这一切都不会损害您的隐私。以前所未有的方式掌控您的回忆。

**🌐 隐私至上，始终如此：**  
您的隐私至关重要。抛弃那些贪求数据的巨头。Simon-Galleria 让您掌控一切。清除 GPS 坐标和相机详情等 EXIF 元数据，让回忆只属于您自己。

**🔒 卓越的安全保护：**  
使用 PIN、图案或指纹保护锁定您的回忆。保护特定的照片、视频或整个应用——由您决定谁可以访问。安心无忧，值得保证。

**🔄 轻松恢复：**  
放心，意外总会发生！Simon-Galleria 内置的回收站让您可以在几秒内恢复已删除的照片和视频。不再丢失珍贵内容，只有纯粹的安心。

**🎨 您的相册，您的风格：**  
自定义外观、感觉和功能，以契合您的风格。从 UI 主题到功能按钮，Simon-Galleria 赋予您渴望的创作自由。

**📷 通用格式自由：**  
JPEG、JPEG XL、PNG、MP4、MKV、RAW、SVG、GIF、AVIF、视频等等——无论您选择何种格式，我们都能守护您的回忆。没有限制，只有无限可能。

**✨ 动态主题的 MATERIAL DESIGN：**  
体验直观 material design 搭配动态主题的美丽。还想要更多？深入自定义主题，让您的相册真正独一无二。
