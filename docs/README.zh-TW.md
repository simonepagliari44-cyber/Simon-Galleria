釋放回憶，而非個人資料。Simon-Galleria 是一款兼具強大功能與隱私保護的終極相片和影片應用程式。沒有廣告，沒有不必要的權限——只有為您量身打造的流暢體驗。

**🖼️ 觸手可及的相片編輯：**  
用我們簡單卻強大的相片編輯器美化您的相片。裁剪、調整大小、旋轉、翻轉、繪製並套用驚豔的濾鏡，這一切都不會損害您的隱私。以前所未有的方式掌控您的回憶。

**🌐 隱私至上，始終如一：**  
您的隱私至關重要。拋棄那些貪求資料的巨頭。Simon-Galleria 讓您掌控一切。清除 GPS 座標與相機詳情等 EXIF 中繼資料，讓回憶只屬於您自己。

**🔒 卓越的安全防護：**  
使用 PIN、圖形鎖或指紋保護鎖定您的回憶。保護特定的相片、影片或整個應用程式——由您決定誰可以存取。安心無憂，值得保證。

**🔄 輕鬆復原：**  
放心，意外總是會發生！Simon-Galleria 內建的回收筒讓您能在幾秒內復原已刪除的相片和影片。不再遺失珍貴內容，只有純粹的安心。

**🎨 您的相簿，您的風格：**  
自訂外觀、感受與功能，以契合您的風格。從 UI 主題到功能按鈕，Simon-Galleria 賦予您渴望的創作自由。

**📷 通用格式自由：**  
JPEG、JPEG XL、PNG、MP4、MKV、RAW、SVG、GIF、AVIF、影片等等——無論您選擇何種格式，我們都能守護您的回憶。沒有限制，只有無限可能。

**✨ 動態主題的 MATERIAL DESIGN：**  
體驗直覺 material design 搭配動態主題的美感。還想要更多？深入自訂主題，讓您的相簿真正獨一無二。
