## 📌 **ခြုံငုံသုံးသပ်ချက်**

**Simon-Galleria** သည် အဆင်ပြေမှုကို မစွန့်လွှတ်ဘဲ သင့်အမှတ်တရများကို အပြည့်အဝ ထိန်းချုပ်လိုသူများအတွက် တည်ဆောက်ထားသော native **Android** ဓာတ်ပုံနှင့် ဗီဒီယိုပြခန်းဖြစ်သည်။ ကြော်ငြာမရှိ၊ ခြေရာခံမှုမရှိ၊ မလိုအပ်သော ခွင့်ပြုချက်များမရှိ- သင့်အတွက် အထူးပြုလုပ်ထားသော လျင်မြန်ပြီး သပ်ရပ်သော အတွေ့အကြုံသာ။

သင့်ဓာတ်ပုံများနှင့် ဗီဒီယိုများကို ကြည့်ရှုခြင်း၊ စီစဉ်ခြင်းနှင့် တည်းဖြတ်ခြင်း၊ အထိခိုက်လွယ်ဆုံးအကြောင်းအရာများကို ဝှက်ထားခြင်းနှင့် built-in recycle bin ကြောင့် ဖျက်လိုက်သောအရာများကို စက္ကန့်ပိုင်းအတွင်း ပြန်လည်ရယူခြင်းတို့ ပြုလုပ်နိုင်သည်။ အရာအားလုံးသည် **သင့်စက်ပေါ်တွင် တိုက်ရိုက်** လည်ပတ်ပြီး ကိုယ်ရေးကိုယ်တာလုံခြုံမှု အပြည့်အဝရှိသည်။

---

## ✨ **အင်္ဂါရပ်များ**

* 🖼️ **built-in ဓာတ်ပုံတည်းဖြတ်ကိရိယာ:** အက်ပ်အတွင်းတွင် ဖြတ်ခြင်း၊ အရွယ်ပြောင်းခြင်း၊ လှည့်ခြင်း၊ မှောက်ခြင်း၊ ရေးဆွဲခြင်းနှင့် filter များ ထည့်သွင်းခြင်း။
* 🔐 **ကိုယ်ရေးကိုယ်တာ ဦးစားပေး:** GPS တည်နေရာနှင့် ကင်မရာအသေးစိတ်များကဲ့သို့သော EXIF metadata များကို ဖယ်ရှားခြင်း။
* 🔒 **အဆင့်မြင့်လုံခြုံရေး:** PIN၊ ပုံစံ သို့မဟုတ် လက်ဗွေဖြင့် ဓာတ်ပုံများ၊ ဗီဒီယိုများ သို့မဟုတ် အက်ပ်တစ်ခုလုံးကို သော့ခတ်ခြင်း။
* ♻️ **built-in recycle bin:** မတော်တဆ ဖျက်လိုက်သော ဓာတ်ပုံများနှင့် ဗီဒီယိုများကို စက္ကန့်ပိုင်းအတွင်း ပြန်လည်ရယူခြင်း။
* 🎨 **dynamic theme များ:** စနစ်ကို လိုက်နာသော အလင်း/အမှောင် theme များဖြင့် Material Design၊ အပေါ် စိတ်ကြိုက် theme များ။
* 📷 **ပံ့ပိုးသော format များစွာ:** JPEG၊ JPEG XL၊ PNG၊ MP4၊ MKV၊ RAW၊ SVG၊ GIF၊ AVIF နှင့် အခြားများစွာ။
* 🔍 **ရှာဖွေခြင်းနှင့် folder များ:** လျင်မြန်သော media ရှာဖွေမှုနှင့် ထည့်သွင်းထားသော၊ ဖယ်ထုတ်ထားသော၊ ဝှက်ထားသော folder များ စီမံခန့်ခွဲခြင်း။
* 🖥️ **wallpaper နှင့် widget:** ဓာတ်ပုံကို wallpaper အဖြစ် သတ်မှတ်ပြီး folder widget ကို home screen တွင် ထည့်ခြင်း။
* 📴 **ချိတ်ဆက်မှု မလိုအပ်:** အက်ပ်သည် လုံးဝ **offline** အလုပ်လုပ်သည်။

## 🔐 **ကိုယ်ရေးကိုယ်တာနှင့် လုံခြုံရေး**

ကိုယ်ရေးကိုယ်တာသည် အက်ပ်၏ နှလုံးသားဖြစ်သည်- အကောင့်မရှိ၊ ဒေတာစုဆောင်းခြင်းမရှိ၊ ပြင်ပလောကနှင့် ချိတ်ဆက်မှုမရှိ။ သော့ခတ်အင်္ဂါရပ်များသည် အက်ပ်တစ်ခုလုံး သို့မဟုတ် သင်ရွေးချယ်သော အကြောင်းအရာကိုသာ ကာကွယ်သည်။ EXIF metadata ဖယ်ရှားခြင်းသည် သင့်တည်နေရာ သို့မဟုတ် ရိုက်ကူးမှုအသေးစိတ်များကို မတော်တဆ မျှဝေမိခြင်းကို တားဆီးသည်။

| ခွင့်ပြုချက် | မည်သည့်အခါ | မည်သည့်အတွက် |
|---|---|---|
| `READ_MEDIA_IMAGES` / `READ_MEDIA_VIDEO` | Android 13+ | စက်ပေါ်ရှိ ဓာတ်ပုံများနှင့် ဗီဒီယိုများကို ဖတ်ရန် |
| `READ_MEDIA_VISUAL_USER_SELECTED` | Android 14+ | ရွေးချယ်ထားသော ဖိုင်များကို ရွေးချယ်စွာ ဝင်ရောက်ရန် |
| `ACCESS_MEDIA_LOCATION` | အမြဲ | EXIF metadata မှ တည်နေရာကို ဖတ်ရန် |
| `SET_WALLPAPER` | တောင်းဆိုချိန်တွင် | ဓာတ်ပုံကို wallpaper အဖြစ် သတ်မှတ်ရန် |
| `POST_NOTIFICATIONS` | Android 13+ | အက်ပ် အသိပေးချက်များ |
| `WRITE_EXTERNAL_STORAGE` | Android 10 အထိ | media များ သိမ်းဆည်းခြင်းနှင့် တည်းဖြတ်ခြင်း |
| `MANAGE_EXTERNAL_STORAGE` | ရွေးချယ်နိုင် | ဖိုင်စီမံခန့်ခွဲမှု အပြည့်အဝ |
| `RECEIVE_BOOT_COMPLETED` | အမြဲ | ပြန်လည်စတင်ပြီးနောက် media စာရင်းကို ပြန်လည်ဆန်းသစ်ရန် |

အက်ပ်သည် network ခွင့်ပြုချက် သို့မဟုတ် ကင်မရာဝင်ရောက်ခွင့် **မလိုအပ်**ပါ။
