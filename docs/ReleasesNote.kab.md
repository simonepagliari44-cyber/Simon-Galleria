## 📌 **Agzul**

**Simon-Galleria** d talella tudrigt n tektakin d tvidyuten n **Android**, i yettwaxedmen i yemdanen yebɣan aḥkam ameqqran ɣef tektiwin-nsen war ma ḍeɛfen tirmit. Ulac adisan, ulac alqem, ulac tisirag n tisirag: ala tirmit tura, tusridt yerna tettwaheggan i keč.

Tzemreḍ ad twaliḍ, ad tesegmiḍ yerna ad tesfekiḍ tektakin-ik d tvidyuten-ik, ad tferneḍ agbur-ik amussnan yerna ad d-tareḍ tɣawsiwin i yettwakkeskisen s tsurif deg akerdis n usefsex. Akk yetteddu **srid ɣef yibenk-ik**, s tbaḍnit tummidt.

---

## ✨ **Timahilin**

* 🖼️ **Asefki n tektakin yettwaskeren:** gzem, beddel tiddi, err, qleb, cireḍ sakin snes filtriyen srid deg usnas.
* 🔐 **Tbaḍnit d tazwara:** kkes tilqem n EXIF am tensiwin GPS d yisefka n tkamirat.
* 🔒 **Taɣellist tamzurt:** sekkweṛ tektakin, tvidyuten neɣ asnas meṛṛa s PIN, s tɣuri neɣ s udm.
* ♻️ **Akerdis n usefsex yettwaskeren:** arefu tektakin d tvidyuten i yettwakkeskisen s tuccḍa deg tsurif.
* 🎨 **Isdisen imussnawen:** Material Design s yisdisen ifsuṭen/iberkanen i ḍefren anagraw, ɣas daɣen isdisen yimeslayen.
* 📷 **Aṭas n yimasaɣen i yettwasefraken:** JPEG, JPEG XL, PNG, MP4, MKV, RAW, SVG, GIF, AVIF d wiyaḍ.
* 🔍 **Anadi d tkaramayin:** anadi arurad n umasay d usefrek n tkaramayin yettwaskeren, yettwakkes neɣ yeffren.
* 🖥️ **Agilal d uwidget:** sers tukt am ugilal sakin rnu widget n tkaramit ɣer ugdil-ik.
* 📴 **Ulac tuqqna i yesra:** asnas yetteddu **offline** s tummidt.

## 🔐 **Tbaḍnit d tɣellist**

Tbaḍnit d wul n usnas: ulac amiḍan, ulac isefka yettwaleqḍen, ulac tuqqna ɣer beṛṛa. Timahilin n usekkeṛ ḥerzent asnas meṛṛa neɣ ala agbur i tferneḍ, ma tukkist n tilqem n EXIF tweǧǧeɛ war ma tessefreḍ tamurt-ik neɣ yisefka n tuṭṭfa.

| Tisirag | Melmi | I wacu |
|---|---|---|
| `READ_MEDIA_IMAGES` / `READ_MEDIA_VIDEO` | Android 13+ | Ɣer tektakin d tvidyuten deg yibenk |
| `READ_MEDIA_VISUAL_USER_SELECTED` | Android 14+ | Anekcum afran ɣer yifuyla yettwafernen |
| `ACCESS_MEDIA_LOCATION` | dima | Ɣer tensa seg tilqem n EXIF |
| `SET_WALLPAPER` | ɣef usuter | Sers tukt am ugilal |
| `POST_NOTIFICATIONS` | Android 13+ | Tilɣa n usnas |
| `WRITE_EXTERNAL_STORAGE` | alamma Android 10 | Sekles sakin sefki amasay |
| `MANAGE_EXTERNAL_STORAGE` | tafrayt | Asefrek ummid n yifuyla |
| `RECEIVE_BOOT_COMPLETED` | dima | Smiren tabdart n umasay deffir tɣuri |

Asnas **ur** yesri tisirag n uẓeṭṭa neɣ anekcum ɣer tkamirat.
